HR Portal — one-time setup

Creates config.js. Your GitHub token is encrypted with your password inside it, so the token is never stored in plain text. Everything happens in your browser.
GitHub → Settings → Developer settings → Fine-grained tokens. Repository access: only this repository. Permission: Contents → Read and write.
  1. Put config.js in the repository root (replace the existing one), next to index.html.
  2. Commit. Open the site and sign in with your password.
